# Interview Vault

A full-stack learning project for saving, organizing, searching, and reviewing interview questions.

## Run locally

Install a current Node.js LTS release, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## What it demonstrates

- Express API routes for reading, adding, and favoriting questions
- JSON persistence (an approachable stand-in for a database while learning)
- Responsive client dashboard with search, filtering, sorting, collections, and a create-question form

## Suggested next production steps

Replace the JSON store with PostgreSQL, add authentication, validate API input, add tests, then deploy the app and connect a GitHub Actions workflow.
